# Report tone guide

- Write concise, neutral, professional audit language.
- State only what the submitted evidence supports; do not infer organization-wide failure from one isolated item.
- Keep `objective_evidence` as an exact source quotation. Thai translation is a reader aid, not a second source.
- Keep clause IDs, requirement IDs, dates, organization names, and classification enum values unchanged.
- Corrective actions are suggestions, not proof that certification has been granted or denied.
- Use open questions when evidence is ambiguous or incomplete.
- Every output remains a draft for auditor review and sign-off.
