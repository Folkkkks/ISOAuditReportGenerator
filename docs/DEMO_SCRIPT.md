# PRD-aligned demo — approximately three minutes

1. 0:00–0:25 Explain evidence-to-draft scope and the auditor sign-off boundary. Upload `data/demo/major-nc-evidence-pack.json`.
2. 0:25–1:05 Generate a draft. Show **Normalized Observations**, the classification, and mapped ISO clause. Explain `Normalizer → Classifier → Clause Mapper → Composer → Judge`.
3. 1:05–1:40 Show the finding, original objective evidence, Thai reader-aid translation, corrective action, and Judge result. State that the original quotation—not the translation—is authoritative.
4. 1:40–2:10 Edit a classification with a reason, save it, and show revision history plus the stale-Judge warning.
5. 2:10–2:35 Open **Evaluation & controls** and run the bundled Judge Block Demo. Explain that the report deliberately overclaims beyond one interview and should be blocked or flagged for human review.
6. 2:35–3:00 Show the final Gold-set metrics, export controls, and draft disclaimer. Disclose that Gold annotations are project-authored and development-reviewed but still await instructor or qualified-auditor sign-off.

Allow for provider latency; a clearly labelled previously generated saved draft may be used if the network is slow. Do not claim that automated evaluation or the Judge replaces qualified human review.
